📥 طريقة التثبيت

🟧 Forge

  1. ثبت Forge لنفس إصدار السيرفر
  2. ضع المودات داخل مجلد mods
  3. شغل اللعبة عبر Forge Profile

🟪 Fabric

  1. ثبت Fabric Loader
  2. ثبت Fabric API إذا كان مطلوب
  3. ضع المودات داخل مجلد mods
  4. شغل اللعبة عبر Fabric Profile

🟨 Paper

هذا النوع لا يحتاج مودات أو لودر عند اللاعب. فقط ادخل بالسيرفر مباشرة.

📦 المودباك

  1. حمل ملف المودباك
  2. حطو في ملف الانشر
  3. شغل اللعبة مباشرة
